# Personal Portfolio

A personal portfolio site that showcases my skills, experience, and projects. It serves as a professional platform to present myself online, highlighting my technical expertise, creative work, and career achievements.

This portfolio was built to present who I am as a developer, my skills, past work, and achievements in a clear, engaging, and accessible way. It is a place for potential employers, clients, and collaborators to learn more about me and explore the projects I have created.


## Features
1. About Me - A brief introduction and professional summary.
2. Skills - Technologies and tools I am familiar with.
3. Projects - Highlights of personal and professional work.
4. Contact - Ways to get in touch with me.
5. Responsive design - Works on both desktop and mobile.

## Built With

### This project primarily uses:
1. HTML
2. CSS
3. JavaScript
